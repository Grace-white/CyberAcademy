Linux Fundamentals

Learn the Linux operating system and build the command-line skills needed for cybersecurity and system administration.

Course Modules

Module 1: Introduction to Linux

Understand Linux, distributions, the terminal, and why Linux is widely used in cybersecurity.

Module 2: Linux File System

Learn the Linux directory structure, files, folders, paths, and basic file management.

Module 3: Linux Commands

Practice essential commands for navigating, creating, copying, moving, and managing files.

Module 4: Users and Permissions

Learn users, groups, file permissions, ownership, and basic privilege management.

Module 5: Linux for Cybersecurity

Explore processes, networking commands, logs, and other Linux skills used in cybersecurity.
