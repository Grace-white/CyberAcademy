Networking Lab

Practice fundamental networking concepts in a safe and controlled learning environment.

Lab 1: Identify an IP Address

Challenge

An IPv4 address identifies a device on an IP network. Identify which of the following is a valid IPv4 address.

  • 192.168.1.25
  • 300.168.1.25
  • 192.168.1
  • 192.168.1.999

Answer: 192.168.1.25

Lab 2: Common Network Ports

Challenge

Match each service with its commonly associated port.

  • HTTP — 80
  • HTTPS — 443
  • SSH — 22
  • DNS — 53

Understanding common ports helps security professionals interpret network traffic and service information.

Lab 3: TCP vs UDP

Challenge

TCP and UDP are two important transport-layer protocols.

TCP provides connection-oriented, reliable communication.

UDP is connectionless and generally provides lower overhead.

Lab 4: Network Troubleshooting

Challenge

A computer cannot reach another authorized device on the network. Which tool can be useful for testing basic connectivity?

Answer: ping

Lab 5: Security Thinking

Challenge

You discover an unfamiliar service running on an authorized laboratory system.

What should you do first?

Answer: Identify and document the service before making changes, while staying within the laboratory's rules and scope.

Lab Rules

  • Practice only in authorized environments.
  • Do not attack systems you do not own or have permission to test.
  • Document your observations.
  • Follow the instructions and scope of each laboratory.
  • Use security knowledge responsibly.
