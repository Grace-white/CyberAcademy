Lab 2: Find Your IP Address on Linux

Practical Exercise

Open a Linux terminal and run: 

ip addr

Look at the output and identify the IPv4 address. IPv4 addresses normally appear next to the inet label.

Your Task

  1. Open your Linux terminal.
  2. Run ip addr.
  3. Identify the active network interface.
  4. Find its IPv4 address.
  5. Record the address for your lab notes.

Common Ports Reference

  • HTTP — 80
  • HTTPS — 443
  • SSH — 22
  • DNS — 53

Understanding common ports helps security professionals interpret network traffic and identify services.

Lab 5: Network Troubleshooting

Scenario Challenge

A computer in your authorized laboratory cannot reach another device on the same network.

You want to perform a basic connectivity test. Which command should you try first?









Practical Exercise

In your own authorized Linux environment, you can use: 

ping -c 4 127.0.0.1

The address 127.0.0.1 refers to the local host. This provides a safe starting point for understanding basic connectivity testing.

Important: Only test systems and addresses that you own or have explicit permission to test.
