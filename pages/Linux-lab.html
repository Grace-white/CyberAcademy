Linux Lab

Practice essential Linux commands, file management, permissions, users, and basic system administration concepts in a safe learning environment.

Lab 1: Navigating the File System

Challenge

Which command displays the directory you are currently working in?

Answer: 

pwd

The pwd command means "print working directory."

Lab 2: Listing Files

Challenge

Which command can be used to list files and directories? 

ls

You can also use options such as ls -l to display additional information about files.

Lab 3: Creating Directories

Challenge

Create a directory named cyber-lab. 

mkdir cyber-lab

The mkdir command creates a new directory.

Lab 4: File Permissions

Challenge

Linux uses permissions to control who can read, write, or execute a file. 

ls -l

The output can show permissions for the file owner, group, and other users.

Lab 5: Finding Information

Challenge

Which command can display information about a Linux command? 

man ls

The man command opens the manual page for a command.

Lab 6: Users and Identity

Challenge

Which command displays the username of the currently logged-in user? 

whoami

Understanding user identity is important when working with Linux permissions and system security.

Lab 7: Safe Cybersecurity Practice

Challenge

You are practicing Linux commands in a cybersecurity laboratory. Before changing system files or settings, what should you do?

Answer: Understand the command, confirm the target, and make sure you are working within the authorized laboratory environment.

Lab Rules

  • Practice only in authorized environments.
  • Understand commands before executing them.
  • Be careful when modifying system files.
  • Do not experiment on systems you do not own or have permission to use.
  • Keep backups of important work.
