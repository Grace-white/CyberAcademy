Network Protocols and Ports

Learn how network protocols allow devices and applications to communicate and how ports identify specific network services.

Lesson 1: What Is a Network Protocol?

A network protocol is a set of rules that devices follow when communicating across a network.

Protocols define how information is formatted, transmitted, received, and understood.

Lesson 2: Common Network Protocols

HTTP

HTTP is used to transfer information between web browsers and web servers.

HTTPS

HTTPS is the secure version of HTTP and uses encryption to protect communication between a browser and a server.

DNS

DNS translates domain names, such as example.com, into IP addresses that computers can use.

SSH

SSH provides secure remote access to systems and is commonly used for Linux administration.

Lesson 3: What Is a Port?

A port is a logical communication endpoint used by network services and applications. Ports help a device determine which application should receive incoming network traffic.

Port numbers range from 0 to 65535.

Lesson 4: Common Ports

Port 22 — SSH

Commonly associated with Secure Shell remote access.

Port 53 — DNS

Commonly used by the Domain Name System.

Port 80 — HTTP

Commonly used for standard HTTP web traffic.

Port 443 — HTTPS

Commonly used for secure HTTPS web traffic.

Lesson 5: Why Protocols and Ports Matter in Cybersecurity

Security professionals need to understand protocols and ports because network services communicate through them. This knowledge helps with network monitoring, security analysis, vulnerability assessment, and defensive configuration.

Key Takeaways

  • Protocols define rules for network communication.
  • Ports identify communication endpoints for services.
  • HTTP and HTTPS are commonly used for web communication.
  • DNS helps translate domain names into IP addresses.
  • SSH provides secure remote access.
  • Understanding protocols and ports is important for cybersecurity.
