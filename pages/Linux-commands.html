Linux Commands

Learn essential Linux commands for navigating the system, managing files, viewing information, and working with the command line.

Lesson 1: Navigating the File System

pwd

Displays the current working directory.

Example: pwd

ls

Lists files and directories in the current location.

Example: ls

cd

Changes the current working directory.

Example: cd Documents

Lesson 2: Working with Files and Directories

mkdir

Creates a new directory.

Example: mkdir practice

touch

Creates a new empty file or updates a file's timestamp.

Example: touch notes.txt

cp

Copies files or directories.

Example: cp notes.txt backup.txt

mv

Moves or renames files and directories.

Example: mv notes.txt documents/

rm

Removes files or directories. Use this command carefully.

Example: rm notes.txt

Lesson 3: Viewing and Searching Information

cat

Displays the contents of a text file.

Example: cat notes.txt

grep

Searches text for matching patterns.

Example: grep "password" notes.txt

Lesson 4: Getting Help

man

Displays the manual page for a command.

Example: man ls

Lesson 5: Why Linux Commands Matter in Cybersecurity

Security professionals frequently use the Linux command line to inspect systems, analyze files, review logs, manage processes, and perform administrative tasks.

Key Takeaways

  • pwd shows your current directory.
  • ls lists files and directories.
  • cd changes directories.
  • mkdir creates directories.
  • cp copies files and directories.
  • mv moves or renames files.
  • cat displays file contents.
  • grep searches text.
  • man provides command documentation.
