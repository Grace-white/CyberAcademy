Reconnaissance & Information Gathering

Learn how security professionals gather and organize information about systems and organizations during an authorized security assessment.

Lesson 1: What Is Reconnaissance?

Reconnaissance is the process of collecting information about a target before a security assessment begins.

In ethical hacking, reconnaissance must always be performed within the approved scope of the assessment.

Lesson 2: Passive Reconnaissance

What Is Passive Reconnaissance?

Passive reconnaissance gathers information without directly interacting with the target systems. Security professionals may use publicly available information and authorized sources.

Examples of Information

  • Public domain information
  • Organization websites
  • Public documentation
  • Publicly available technology information
  • Information provided by the organization

Lesson 3: Active Reconnaissance

Active reconnaissance involves interacting with systems or services to gather information.

Because active reconnaissance can generate traffic or alerts, it should only be performed when it is explicitly authorized and within the agreed testing scope.

Lesson 4: Information Categories

Network Information

Information about authorized network ranges, infrastructure, services, and connectivity.

Technology Information

Information about operating systems, applications, frameworks, and other technologies used by the organization.

Organizational Information

Information that helps security professionals understand the organization's structure and security environment.

Lesson 5: Organizing Reconnaissance Results

Collected information should be documented carefully. Security professionals should separate verified facts from assumptions and record the source of important information.

  • Record useful findings clearly.
  • Identify the source of information.
  • Verify important information when possible.
  • Stay within the authorized scope.
  • Avoid collecting unnecessary sensitive information.

Lesson 6: Why Reconnaissance Matters

Good reconnaissance helps security professionals understand the environment before conducting further security testing.

It can help identify systems, technologies, and potential areas that require additional security review.

Safe Practice

Reconnaissance techniques should only be practiced on systems you own or on systems where you have explicit permission to conduct security testing.

Key Takeaways

  • Reconnaissance is an information-gathering phase.
  • Passive reconnaissance uses information without directly interacting with target systems.
  • Active reconnaissance interacts with systems and requires authorization.
  • Information should be documented and verified carefully.
  • Reconnaissance must remain within the approved scope.
