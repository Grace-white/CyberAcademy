Linux File System

Learn how Linux organizes files and directories and how users navigate and manage the file system.

Lesson 1: Understanding the Linux File System

Linux organizes files and directories in a hierarchical structure. Everything begins at the root directory, represented by a forward slash.

The root directory is written as: /

Lesson 2: Important Linux Directories

/home

Contains the personal directories and files belonging to regular users.

/etc

Contains many system configuration files.

/var

Contains variable data such as logs and other files that change while the system operates.

/tmp

Used for temporary files created by applications and users.

/usr

Contains many user programs, libraries, documentation, and other system resources.

Lesson 3: Files and Directories

A file stores information, while a directory is used to organize files and other directories.

Linux allows users to create, remove, copy, move, and organize files and directories using commands.

Lesson 4: Absolute and Relative Paths

An absolute path describes the complete location of a file starting from the root directory.

A relative path describes a location based on the user's current directory.

Lesson 5: Why the File System Matters in Cybersecurity

Understanding the Linux file system is important in cybersecurity because security professionals often work with configuration files, logs, applications, permissions, and system data.

Key Takeaways

  • The Linux file system starts at the root directory.
  • Directories organize files and other directories.
  • /home contains user directories.
  • /etc contains many configuration files.
  • /var commonly contains logs and changing system data.
  • Understanding paths is essential when working in Linux.
