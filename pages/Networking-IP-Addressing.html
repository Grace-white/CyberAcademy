IP Addressing

In this module, you will learn how IP addresses identify devices on a network and how networks use addresses to deliver data to the correct destination.

Lesson 1: What Is an IP Address?

An Internet Protocol, or IP, address is a numerical address assigned to a device on a network. It allows devices to be identified and communicate with one another.

For example, an IPv4 address may look like:

192.168.1.10

Lesson 2: IPv4 Addresses

IPv4 addresses contain four numbers called octets. Each octet can have a value from 0 to 255.

An IPv4 address is commonly written in this form:

192.168.1.10

Lesson 3: Private and Public IP Addresses

Private IP Address

A private IP address is used inside a local network, such as a home, school, or office network.

Public IP Address

A public IP address is used to identify a network or device on the public Internet.

Lesson 4: Subnet Masks

A subnet mask helps determine which portion of an IP address represents the network and which portion represents a device on that network.

A common example is:

255.255.255.0

Lesson 5: Why IP Addressing Matters in Cybersecurity

Understanding IP addressing is important in cybersecurity because security professionals need to identify systems, understand network boundaries, analyze traffic, and investigate network activity.

Key Takeaways

  • IP addresses identify devices on networks.
  • IPv4 addresses contain four octets.
  • Private addresses are used inside local networks.
  • Public addresses are used on the Internet.
  • Subnet masks help identify network and host portions.
  • IP addressing is fundamental to network security.
